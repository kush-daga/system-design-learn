Final review: across the whole book

Mixed questions from every chapter. If any feel shaky, the chapter is linked in the answer.

How should you split a 45-minute system design interview across the four steps?

Understand the problem and scope: 3–10 min. High-level design and buy-in: 10–15 min. Deep dive: 10–25 min. Wrap up: 3–5 min. (Ch 3)

In master-slave replication, what happens when the master database goes offline?

A slave is promoted to be the new master, and a new slave replaces the old one for replication. (Ch 1)

Which rate-limiting algorithm allows short bursts and is used by Amazon and Stripe?

The token bucket. (Ch 4)

Why do virtual nodes improve consistent hashing?

Each server owns many small partitions, so keys spread more evenly. The standard deviation is about 10% of the mean with 100 virtual nodes and 5% with 200. The cost is more space for the virtual-node metadata. (Ch 5)

With N replicas, write quorum W and read quorum R, when is strong consistency guaranteed?

When W + R > N (typically N = 3, W = R = 2), because at least one node overlaps between the write set and the read set. (Ch 6)

What is the Snowflake ID bit layout?

1 sign | 41 timestamp | 5 datacenter | 5 machine | 12 sequence. (Ch 7)

URL shortener: 301 or 302 redirect if you care about click analytics?

302 (temporary). Every click then reaches your servers. A 301 is cached by the browser, which reduces server load but hides repeat clicks. (Ch 8)

Which data structures implement a crawler's "URL Seen?" check?

A Bloom filter or a hash table. (Ch 9)

How does a notification system avoid losing notifications?

It persists them in a notification log database and retries delivery. Dedupe by event ID because exactly-once delivery can't be guaranteed. (Ch 10)

News feed: fanout on write or on read?

A hybrid. Push (fanout on write) for most users, so reads are fast. Pull (fanout on read) for celebrities and users with huge follower counts, to avoid overloading the system. (Ch 11)

Why does the chat system use WebSocket?

It's a persistent, bi-directional connection the server can push messages over. It starts as HTTP and is upgraded, and it uses ports 80/443, so it generally works through firewalls. (Ch 12)

Autocomplete: how do you make getting the top-k suggestions for a prefix fast?

Limit the max prefix length and cache the top-k queries at every trie node. Both lookup steps then become ~O(1). (Ch 13)

YouTube: how do you let only authorized users upload straight to cloud storage?

Give them a pre-signed upload URL from the API servers. (Ch 14)

Google Drive: why split files into blocks?

For delta sync (only modified blocks are uploaded) and per-block compression. Both save bandwidth. Dropbox caps blocks at 4 MB. (Ch 15)
